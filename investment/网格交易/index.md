# 网格交易

我对网格交易不算陌生，在微信公众号`ETF做小做底 ETF网格 狼哥`有详细了解过，这个公众号提供了实盘，但收益不高，后面也就没在关注了。另一个公众号`研究员雷牛牛`也提过，4%买入的方式。

这次因为券商费率低的关系，网格交易引起了我的注意。网格交易策略的内容就不复述了。

网格交易步骤：

1. 设置网格上下限，一般是52周的价格范围。比如0.590~0.875。
2. 确定投入的总金额。一般看仓位占比计算出来，此处假设5W。
3. 确定网格数量。比如10个网格，每个网格的间距是0.285。
4. 确定网格交易金额。总金额除以网格数量，就是每个网格的交易金额。此处5W/10=5000元。

注意事项

1. 计算好交易成本。像ETF费用最低费用0.2元，费率是0.005%，那么单笔最低金额是4000元。一买一卖就是0.4元，费率是0.01%，只要网格间距大于0.01%，就可以覆盖成本。
2. **不能选择规模小的ETF**。规模小的ETF，平时成交量小，流动性不足，会出现部分成交的情况，如果是市价成交，则滑点过大的情况。规模至少得10亿（医疗器械5亿都不行），越大越好。
3. **如果有底仓，并想保持底仓，可以设置最大净卖出=当前数量-底仓数量**。比如当前数量是60000，底仓是50000，那么最大净卖出是10000，避免因为行情一路上涨，导致底仓被卖出。或者通过价格范围限制网格只在固定区间执行，这种方式需要计算价格范围。
4. 网格交易金额要考虑交易最低佣金。以ETF的最低佣金0.2元，费率是0.005%为例，那么单笔最低金额是4000元。
