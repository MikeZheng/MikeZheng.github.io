### 🪨 一、煤炭的“身份证”：分类与分级

要理解煤炭，首先要弄明白它的“品种”和“牌号”。煤炭分为按煤化程度分的“大类”和按用途分的“用途分类”两个维度：

*   **1. 按煤化程度：三大基础品类**
    这是国际通用的煤炭分级方式，由中国煤炭分类体系（GB/T 5751-2009）定义，也是理解煤炭品级的根本。

| 大类 | 关键特征 | 感官与挥发分 | 常见应用 |
| :--- | :--- | :--- | :--- |
| **褐煤** | 煤化程度最低，含水量高、热值低、燃点低。 | 外观呈褐色，燃烧时火焰大、烟尘大。 | 主要用于发电。经济状况不好时，有电厂会用褐煤降低成本。 |
| **烟煤** | 煤化程度中等，挥发分较高，热值也较高。 | 呈黑色且有光泽，燃烧时烟尘较大。 | 这是炼焦煤的主要来源，也是动力煤的重要组成部分。 |
| **无烟煤** | 煤化程度最高，固定碳含量高、污染小。 | 呈黑色且有金属光泽，燃烧时火焰大但无烟。 | 主要用于民用、化工合成氨及高炉喷吹等。 |

*   **2. 按最终用途：市场主流划分**
    在市场交易中，我们通常按用途来划分。

| 类别 | 细类 | 典型用途 |
| :--- | :--- | :--- |
| **动力煤** | —— | 主要用于燃煤发电（核心）、机车推进和工业锅炉。褐煤、烟煤和无烟煤中都有一些煤种属于动力煤。 |
| **炼焦煤** | 气煤、肥煤、主焦煤、瘦煤等 | 主要用于钢铁行业，在焦炉中隔绝空气加热，炼制成焦炭。高炉炼铁需要焦炭作为骨架、还原剂和热源。 |
| **化工煤** | 无烟块煤等 | 主要用于煤化工产业，如煤制油、煤制气、合成氨等。 |

### 🔥 二、煤炭的“价值内核”：热值详解

热值，行话常说的“**大卡**”，是衡量煤炭最重要的指标。

*   **含义与常用单位**：指单位质量的煤完全燃烧后释放的热量。行业常用单位是 **千卡/千克 (kcal/kg)** 或 **大卡/千克 (kcal/kg)**，1大卡=1千卡。

*   **高位发热量与低位发热量**：这是两个极易混淆却核心的概念。简单说，**高位发热量是理论最大值，低位发热量是实际可用值**。
    *   **高位发热量**：燃烧产物中的水蒸汽被完全冷凝成液态水，释放了全部汽化潜热。**国际通用，不受水分影响，更能反映煤炭本身品质**。
    *   **低位发热量**：排烟温度较高（约150℃），水蒸汽以气态排走，未计算其汽化潜热。**国内贸易常用，最能反映实际应用中释放的有效热量**。
    *   由于未扣除水分汽化热，**低位发热量约比高位发热量低300-600 kcal/kg**。

*   **“收到基”(`ar`)”和“空气干燥基”(`ad`)**：煤炭的四种常用基准，用来标明煤是在什么状态下被化验的。
    *   **收到基 (as received, `ar`)**：煤炭“原汁原味”的状态，包括全部水分（外在+内在）。**价格交易的结算依据**，最有现实意义。
    *   **空气干燥基 (air dried, `ad`)**：煤样移除外在水分，仅含内在水分，用于实验室分析。**可比性强，常用于签订质量合同**。
    *   **干燥基 (dry, `d`)**：移除所有水分，用于分析灰分、硫分等。
    *   **干燥无灰基 (dry ash-free, `daf`)**：移除所有水分和灰分，主要用于挥发分和元素分析。

*   **关键换算**：若低位发热量为Qnet,ar=5000 kcal/kg，根据换算（1kcal=4.1816kJ），其热值约为**20.9 MJ/kg**。

*   **参考标准**：国际贸易与学术研究常以 **7000 kcal/kg** 的发热量作为 **1公斤标准煤** 的参考基准。

### 💰 三、煤炭的“价格密码”：多种计价方式

煤炭价格因交付环节和运输成本而变化。

| 术语 | 解析 | 包含成本 |
| :--- | :--- | :--- |
| **坑口价** | 在煤矿坑口直接交易的价格，类似“出厂价”。 | 煤炭开采成本 + 煤矿利润 + 各项税费。 |
| **车板价** | 煤炭已装上火车但尚未发车时的价格。 | 坑口价基础上增加短途运输费、装卸费、站台费等。 |
| **平仓价 (FOB)** | 煤炭运抵港口并装船后的价格。 | 车板价基础上增加铁路运费、港杂费、港建费等。 |
| **到厂价** | 煤炭运送至最终用户（如电厂）工厂的价格。 | 平仓价基础上增加海运、汽运等全部运输费用。 |

了解了计价方式，再来看看市场结算：

| 术语 | 解析 |
| :--- | :--- |
| **长协价 vs 现货价** | **长协价**（年度长协）是买卖双方签长约锁定的价格，相对稳定；**现货价**随市场波动，反应即时供需。 |
| **挂牌价 vs 市场价** | **挂牌价**是煤矿在电商平台、资讯网站公开的价格；**市场价**则是最终成交的实际价格。 |

### 📋 四、其他实用术语

*   **原煤**：从毛煤中简单选出大块矸石后的产品，你可能需要进一步加工。
*   **商品煤**：可直接销售的原煤或洗选煤。
*   **洗选煤**：经过洗选加工，去除杂质后的煤炭产品，灰分和硫分更低。
*   **煤质指标**：热值 (Q)、灰分 (A)、全硫 (St)、挥发分 (V) 和水分 (M) 这五大指标，是定价和使用的核心。
*   **主产地**：**“三西”地区**（山西、陕西、蒙西）是我国煤炭主产区。
*   **主要港口**：秦皇岛港、黄骅港、曹妃甸港等是“北煤南运”的重要水运节点。
*   **重要铁路线**：**大秦铁路**（大同至秦皇岛）和朔黄铁路等是煤炭运输的“动脉”线路。
*   **交易名词**：**大卡/Kcal** (发热量)、**吨** (重量)、**短盘** (短途汽运)。
*   **价格单位**：报价通常为**元/吨** (RMB/t)。

### 📈 五、补充：2025-2026年煤炭行业动态

*   **2025年回顾**：全年价格**先抑后扬**。以秦皇岛港5500大卡动力煤为例，均价最低跌至6月的**610元/吨**，后在“反内卷”政策推动下，于12月反弹至约**813元/吨**。
*   **2026年展望**：机构预测价格有望**平稳上涨**。一季度港口均价约**716元/吨**，同比微跌0.96%。截至4月15日，秦皇岛港5500大卡报价为**768元/吨**。
*   **核心影响因素**：**“反内卷”政策**带来的产能收缩预期、安全核查趋严（如2026年施行的新安全规程）、进口煤补充效果有限是三大支撑力量。
