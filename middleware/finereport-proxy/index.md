# 帆软代理

帆软代理，是帆软服务器的上游应用。请求先经过帆软代理，再由帆软代理再转发给帆软服务器。

## 作用

1. 安全。帆软的漏洞的风险级别很高，屏蔽报表用不到的URL，使用更安全的序列化方式，都可以降低帆软服务器被攻击的风险。
2. 负载均衡。帆软服务器的会话是多台帆软服务器间是不互认的，所以请求需要通过IP_HASH的方式实现集群的负载均衡。但有些环境，很难做到IP_HASH，所以帆软代理可以维护集群的会话，实现负载均衡。
3. 鉴权。帆软的报表页面会集成到其他系统，帆软的会话和其他系统是互不认识的，所以需要代理来做外部系统的鉴权。

## 代理功能

1. 请求转发。代理要转发请求到帆软服务器。如果请求携带了sessionID，代理要转发给生成该sessionID的帆软服务器上。
2. 请求和响应的包装。代理要包装帆软的请求，修改帆软的响应，尤其是响应里的URL。
3. 会话管理。代理要维护帆软集群的会话，定时延长会话的有效期。
4. 同时支持多个第三方系统。代理要识别请求的来源系统，并调用来源系统的鉴权接口，实现外部系统的鉴权。
5. 负载均衡。代理可以对接Kubernetes、Nginx等负载均衡器，实现集群的负载均衡。
