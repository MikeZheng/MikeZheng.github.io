# 域名

计算机网络中的IP地址是用于标识网络中设备的唯一标识符。域名则是人类可读的名称，用于替代复杂的IP地址。通过将域名映射到IP地址，用户可以更方便地访问网络资源。域名系统（DNS）负责实现这一映射关系。

## 域名分类

域名分类如下：

1. **顶级域名（TLD）**：位于域名最末尾的部分，例如.com、.org、.net等。
2. **二级域名**：位于顶级域名之前的部分，例如example.com中的example。
3. **三级域名**：位于二级域名之前的部分，例如sub.example.com中的sub。
4. **四级域名**：位于三级域名之前的部分，例如www.sub.example.com中的www。

## 域名注册

1. 使用云服务商（如阿里云、AWS等）进行域名注册。
2. 购买域名后，需要将域名解析到服务器IP地址。可以通过修改DNS记录来实现。
3. 域名解析通常包括A记录和CNAME记录。A记录用于将域名指向一个IPv4地址，而CNAME记录用于将域名指向另一个域名。
4. 完成域名注册和解析后，域名就可以正常使用了。
